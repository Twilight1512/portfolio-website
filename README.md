# Portfolio — Mahbubul Alam Tuhin

A responsive, single-page portfolio starter built with plain HTML, CSS, and JavaScript. No build step or dependencies required.

## Make it yours

1. Your name is already set. In `index.html`, replace `[your role]`, `[your disciplines]`, and `[CITY, COUNTRY]` with your details.
2. Replace the three sample project cards with real work. Keep each project focused on the problem, your contribution, and the outcome; update its year and skill tags too.
3. Change `hello@example.com` and the LinkedIn link in the contact and footer sections. The GitHub link already points to `Twilight1512`.
4. Adjust colors, typography, and layout in `styles.css`. The main theme colors are CSS variables at the top of the file.
5. Update the page title and description in the `<head>` for search and sharing.

## Files

- `index.html` — page content and project showcase
- `styles.css` — responsive layout, visual system, and theme
- `script.js` — mobile navigation and current-year footer
- `.github/workflows/deploy.yml` — publishes the site to GitHub Pages when changes are pushed to `main`

## Preview locally

Open `index.html` in a browser, or serve this folder with any static file server. For example, with Python installed:

```sh
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages

The included workflow deploys on every push to `main`. In the repository, open **Settings → Pages** and choose **GitHub Actions** as the build and deployment source if it is not already selected. After the first successful workflow run, GitHub will show the live site URL there.

## Keep your work organized

Use one project card per case study. Keep the title, year, short summary, and tags consistent, then link the card to a dedicated project page or a detailed case-study section as your portfolio grows. Commit related updates with clear messages so the portfolio stays easy to maintain.
